# WakeUpPlz

포커스 디자인의 SwiftUI 기상 인증 프로토타입. iOS 26 이상, iPhone용. 모든 설정과 연락처는 기기에 저장하며 서버를 사용하지 않습니다.

## 실행

1. `WakeUpPlz.xcodeproj`를 Xcode에서 엽니다.
2. iPhone 시뮬레이터를 선택하고 Run을 실행합니다.
3. 실제 iPhone 설치 시 Signing & Capabilities에서 본인의 Personal Team을 선택합니다. Apple 계정 로그인과 기기 신뢰/개발자 모드 설정은 사용자가 진행해야 합니다.

처음 실행하면 알람과 자동화용 알림 예약은 꺼져 있습니다. 연락처도 빈 상태입니다. 연락처를 등록하는 것만으로 문자가 전송되지 않습니다.

## 구현 범위

- 홈, 채팅 인증, 설정, 월별 달력/날짜 범위 휴무, 사운드 화면
- 시스템/라이트/다크 테마, 슬레이트 그레이/모카 브라운
- iOS 연락처 선택기에서 이름과 특정 번호 가져오기; 직접 입력 보조
- 사용자 지정 인증 문구, 당일 조기 인증, 1분 간격 3회 요청 및 인증 후 남은 회차 취소
- AlarmKit 예약과 중지 의도 처리 후 10초 재알림
- 알람/알림은 앞으로 7일간 예약하고 앱을 열거나 설정을 바꿀 때 갱신
- 기본 사운드 3개, 미리 듣기, 30초 이하 개인 오디오를 CAF로 변환하여 가져오기
- 번들 공휴일(2026–2027), 주말, 직접 등록 휴무 제외
- 단축어용 발송 요청 JSON AppIntent와 실제 메시지를 보내지 않는 규칙 테스트 화면

## 실제 기기에서 검증할 항목

프로토타입 빌드 성공은 실사용 신뢰성 검증 완료를 뜻하지 않습니다.

- AlarmKit 잠금 화면, 중지/재알림, 기상 인증 후 취소, 앱 종료/재부팅/권한 변경
- iOS 27 알림 자동화 → AppIntent → 메시지 보내기. iOS 26에서 시각 변경마다 자동화를 편집하지 않는 동일 흐름은 미확인
- 실제 메시지 발송, 잠금 상태 실행, 여러 수신자, 첫 회차 후 인증 시 후속 회차 미발송
- 실제 문자 시험은 사용자에게 수신자·내용·횟수를 지정받은 뒤 진행
- 무료 Personal Team 서명 만료 및 갱신 후 재설치. 새 프로비저닝 만료일이 실제 연장되었는지 확인 필요

## 단축어 계약

`WakeUpPlz 미인증 발송 요청 가져오기`는 현재 회차 시작 후 60초 안이고, 미인증/근무일이며, 알림 예약이 활성화됐을 때 JSON을 한 번 반환합니다. 그 외에는 빈 문자열입니다. 늦게 실행됐을 때 지난 회차를 몰아서 보내지 않습니다.

```json
{"id":"2026-10-22-0","ordinal":1,"recipients":["등록한 번호"],"text":"설정한 문자 내용"}
```

단축어는 빈 문자열이면 종료하고, JSON을 사전으로 읽은 뒤 `recipients`의 각 번호에 `text`를 보냅니다. 앱은 요청을 전달하기 전에 소비 상태를 저장하므로 중복 전달을 막습니다. **단축어 전송 실패 시 요청을 자동 재시도하지 않으며 수신 성공을 알 수 없습니다.** 연락처 선택 권한과 메시지 자동 발송 권한은 별개의 동작입니다.

## 제한

알람이 iPhone 하드웨어의 최대 음량을 초과하거나 사용자 음량을 무조건 덮어쓸 수 없습니다. 시스템 중지를 차단하지 않습니다. 공휴일 데이터 온라인 갱신은 아직 없으며 지원 연도 밖에서 공휴일 제외를 켜면 문자 요청은 생성하지 않습니다. 임시공휴일은 직접 휴무로 등록할 수 있습니다.

## 개발

- 화면 전용 컴포넌트는 Features 안에 colocate, 공통 디자인만 DesignSystem에 배치
- 순수 도메인 규칙은 Swift Package로 테스트; 화면마다 패키지를 만들지 않음
- `swift test` — 일정/휴무/인증/회차 테스트
- `python3 scripts/generate-project.py` — Swift 파일·기본 WAV를 스캔하여 Xcode 프로젝트 재생성
- `scripts/check-signing.sh /path/to/WakeUpPlz.app` — 서명 프로필 만료일 확인
- `scripts/renew-signing.sh [기기 UDID]` — 캐시된 무료 프로필을 `.local/`로 옮겨 새 7일 프로필을 발급받고, 빌드 후 iPhone에 설치. 기기는 인자 > 마지막 사용 기기 > 연결된 iPhone 순
- `scripts/install-auto-renew.sh` — launchd로 3시간마다 `scripts/auto-renew.sh` 실행. 설치본 만료 36시간 전부터 갱신 시도, 결과는 macOS 알림과 `.local/auto-renew.log`. `--uninstall`로 제거
- 앱 설정 화면에 서명 만료일 표시, 만료 24시간 전 로컬 알림

자세한 제품 결정과 미검증 내용은 `docs/`에 있습니다.

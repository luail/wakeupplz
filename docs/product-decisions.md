# WakeUpPlz · 제품 결정

현재 단계: 사용자가 포커스 시안을 승인했고, SwiftUI 프로토타입 구현 및 검증 중이다.

## 확정된 동작

- 개인용 iPhone 앱. 서버 및 외부 문자 발송 서버를 사용하지 않는다.
- iPhone 15 Pro 우선. iOS 26 이상을 목표로 하되 핵심 자동화가 iOS 27을 요구하면 사용자는 업데이트할 수 있다. iPhone Duo 최적화는 범위에서 제외한다.
- 기본 알람 08:20. 첫 문자는 항상 알람 10분 뒤(2026-10-23 사용자 결정), 앱에서는 알람 시각만 변경한다.
- 기상 인증은 당일 알람 시각부터 가능하다(2026-10-23 사용자 결정: 미리 인증 후 다시 잠드는 것 방지). 인증 성공 시 당일 남은 알람과 문자를 취소한다.
- 오늘 추가 알람(낮잠 등, 2026-10-23 사용자 결정): 홈에서 오늘 하루 한 번 더 울릴 시각을 켠다. 기본 알람과 별개로 인증하며, 미인증 시 같은 규칙(10분 뒤 1분 간격 3회)으로 연락처에 문자를 보낸다. 주말·휴무와 관계없이 울린다. 인증 시 이미 울린 알람만 끝나고, 아직 울리지 않은 추가 알람은 남는다.
- 기본 인증 문구 `일어났어!`. 사용자가 변경할 수 있으며 문구와 정확히 일치해야 한다.
- 알람이 중지되더라도 잠시 후 다시 울리는 동작을 허용한다. 시스템 최대 출력을 초과하거나 중지를 완전히 차단한다고 약속하지 않는다.
- 미인증 문자: 1분 간격 총 3회. 도중 인증하면 아직 실행되지 않은 회차는 취소한다. 이미 발송된 메시지는 회수할 수 없다.
- iMessage 허용. 여러 수신자를 선호하되 기술 부담이 크면 1명 우선.
- 주말·대한민국 법정 공휴일·개인 휴무 제외. 내일 쉬기 등록/취소, 날짜 범위 등록 및 수정/삭제.
- 단축어 최초 1회 설정은 허용한다. 알람/문자 시각 변경마다 단축어를 편집하게 만들지 않는다.
- 유료 Apple Developer Program 가입하지 않는다. 무료 서명/재설치 자동화 가능성을 검증한다.

## 디자인

- 라이트: Primary #5B6770, Background #F8F9FA, Surface #FFFFFF, Text #1A1D21, Secondary #6B7280, Border #E5E7EB.
- 다크: Primary #8B7355, Background #1A1816, Surface #24221F, Text #F5F4F2, Secondary #A8A29E.
- 포커스 시안 확정. 라이트/다크 팔레트 유지. 실제 앱의 연락처는 빈 상태에서 시작한다. 연락처 선택기를 기본 입력 방식으로 사용하고 직접 입력은 보조로 제공한다.
- 화면: 홈, 기상 인증, 설정, 휴무일, 알람 사운드. 라이트/다크 전환 지원.

## 미검증 사항

1. 잠금 상태에서 알림 기반 단축어 실행 → 인증 상태 재확인 → 각 회차 문자 발송.
2. 알람 중지 후 재예약/재알림, 권한 취소·앱 종료·재부팅에 따른 한계.
3. 무료 계정으로 실제 설치 및 갱신. 새 프로비저닝 만료일을 읽어서 갱신이 실제 연장됐는지 확인해야 한다.
4. 예약 작업은 Mac 켜짐·실행 앱·기기 접근·서명 인증 상태에 의존한다. 단순 재빌드만으로 7일 만료가 갱신됐다고 판정하지 않는다.
5. 국가 공휴일/임시공휴일 데이터 갱신 정책. 출처 및 지원 연도를 표시한다.

실제 문자 전송 테스트는 수신 번호·내용·횟수를 정한 후 사용자의 명시적 지시를 받아 진행한다.

# WakeUpPlz 아이콘

사용자 선택: ② 해와 체크 (2026-10-22).

내장 image_gen으로 시안 3개와 선택한 안의 라이트/다크 최종 이미지를 생성했다. 최종 원본은 불투명 정사각형이며, iOS 아이콘 규격에 맞춰 1024×1024로 리샘플링했다. 모서리 마스크는 iOS가 적용한다.

앱 연결: `WakeUpPlz/Resources/Assets.xcassets/AppIcon.appiconset/`. 기본 이미지는 AppIcon-Light.png, 어두운 홈 화면용 이미지는 AppIcon-Dark.png. 앱 내부 테마 선택과 홈 화면 아이콘 모드는 서로 독립된 iOS 설정이다.

## 최종 이미지 생성 지시

선택된 시안을 편집 대상으로 넣고 각각 왼쪽 라이트/오른쪽 다크 아이콘만 추출하도록 지시했다. 승인된 해 링·체크·두 광선의 모양과 비율, 새틴 재질을 유지하고, 보드·다른 아이콘·외부 그림자·둥근 외곽 마스크를 제거했다. 1024×1024 불투명 사각형, 모서리까지 이어지는 배경, 약 64% 폭의 중앙 심볼, 라이트 #F8F9FA/#5B6770, 다크 #1A1816/#8B7355, 텍스트·워터마크·추가 장식 없음.
